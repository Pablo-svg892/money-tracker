# Shared House Budget Tracker
 
A console application built in C# (PRG182) that helps students living in a shared house track their household budget together — who spent what, how much has been saved, and where the money is going.
 
## Features
- Add and subtract transactions (income and expenses)
- Track the running balance and total savings
- Record who made each transaction — with the option to stay anonymous
- Timestamp on every transaction
- Categorize transactions (e.g. groceries, utilities, rent)
- View a summary of all transactions and spending by category
## Why I built this
Living in a shared house means shared expenses, and it's easy to lose track of who paid for what. This project was built to solve that — a simple, no-frills way for housemates to log transactions and see exactly where the household's money is going, without needing a spreadsheet or a banking app.
 
## What I learned
- Structuring a multi-feature console application in C#
- Working with date/time values for timestamps
- Designing simple data categorization
- Handling optional/anonymous input
- Building running totals and summaries from a list of records

## Possible improvements
- Save transaction history to a file so it persists between sessions
- Add a monthly budget limit with warnings when it's exceeded
- Export a summary report (e.g. to CSV or PDF)
- Move from console to a simple GUI or web interface
